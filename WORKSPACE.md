# Prime Solution AI — Development workspace

This branch is an isolated workspace for developing and testing Project Inspector Lab changes.

## Rules
- Do not deploy or change the live Project Inspector website without explicit approval.
- Develop changes on feature branches, then review and test before merging into `main`.
- Never commit passwords, API keys, or client data.
- Keep changes focused and document what was actually tested.

## Local setup
```sh
npm install
npm start
```

The existing package.json uses Node.js and Express. Check the actual app code and tests before claiming the project runs successfully.
